Requirements

  • Windows 10 22H2 or Windows 11, 64-bit. Windows on ARM is not supported by this build.
  • OpenCode Desktop. Required. Install the official desktop build first; the OpenDeath wizard checks for it and links to the download if it is missing.
  • Internet access. Needed for provider sign-in, model requests, and optional components.
  • About 1.3 GB free disk space. The portable build also needs room for its extracted runtime.
  • No administrator account. Both builds install per user. Administrator rights may be needed only if you choose to install a system-wide VPN client.
OpenDeath is not OpenCode. It installs alongside OpenCode Desktop, uses its own executable and data folder, and never launches or modifies the OpenCode app.

Install and first launch

With the setup wizard

  1. Download and verify OpenDeath-Setup-1.0.3.exe against SHA256SUMS.txt.
  2. Run the wizard. It installs Cloudflare WARP first, then checks for OpenCode Desktop, before it copies anything.
  3. Choose a destination, shortcuts, and any optional VPN clients you want. WARP is required.
  4. Finish the wizard and launch OpenDeath from the new shortcut.

With the portable build

Put OpenDeath-Portable-1.0.3.exe in a folder you control and run it. It extracts to a temporary folder and leaves no shortcuts. Settings still live in your Windows profile, so moving the executable does not lose them.

The first window

The network deck sits under the title bar. Start with Auto for a healthy route, or None for a direct connection. Open Settings → Basic to sign in to a provider. There is no OpenDeath account and no separate OpenDeath server.

Routes

A route is how OpenDeath reaches the network. Each mode has its own setup and status; switching modes does not close the current session.

Fix connection diagnoses the selected route, rebuilds it if needed, and reports the result. Status shows the current exit IP and route health. Neither button restarts the session.

Recovery controls

Reset limit

Clears the current allowance and retries the last prompt in one action. Use it when a provider reports a free limit but the route itself is healthy.

Auto-rotate

Watches for a free limit, finds another exit, verifies it, and sends continue to every waiting chat. It makes up to 50 attempts, remembers burned exit IPs for 24 hours, and stops when the route is healthy. A per-chat delay and a rotation lock prevent the same limit from triggering twice.

Auto mode tries the routes your machine can actually reach: WARP first, then the free proxy pool, then None. WARP is required and is the default route; a from-scratch setup stops and asks for it instead of silently choosing a fallback. If a route reports a new exit IP but the IP does not change, OpenDeath says so and moves down the list instead of claiming success. A manual New IP click rotates even when the auto checkbox is off.

Relaunch resume

Waiting chats are written to pending.json. On the next launch OpenDeath restores them and resumes once the new route is ready. If you close the app in the middle of a rotation, the next launch continues from the last saved state.

Fast mode

Skips the pre-check before rotation. It is quicker on a network you trust and slower to fail on one you do not. Leave it off unless you know the route pool is healthy.

Personalization

Settings → Personalization controls the theme, background, rainbow accents, and text color. The default is dark. Light and system themes are available, and every color control keeps body text readable.

Themes are listed by color rather than by product name: Peach, Cornflower, Lavender, Violet Black, and the rest of the set. The underlying theme ID never changed, so a theme you picked before the update is still selected and only its label reads differently.

Beside the theme picker:

  • Accent color — eight presets plus a custom picker. It tints buttons, focus rings, chips, and the active route marker.
  • Corner roundness — a 0–200% slider that rewrites the radius scale. 0% is a square, hard-edged window; 200% is fully soft.
  • Deck density — compact fits every slot on one row, comfortable gives each slot more breathing room.
  • Status band — show or hide the bottom strip.

Voice dictation is available anywhere the composer is. The keyboard shortcut is shown in the composer menu; it can be changed in Settings.

The HUD editor

Every control on the network deck is a slot, and you own the order. Open Settings → HUD or press Edit HUD on the deck itself.

  • Drag a slot with the mouse to move it. The drop lands where the eye saw it, even when hidden slots sit between two visible ones.
  • Click a slot and use the arrow buttons to move it one position at a time.
  • Toggle the eye to hide a slot. Hidden slots keep their position and can be restored at any time.
  • Reset returns the deck to the shipped order.

The layout is saved the moment you move something and survives a restart. Slots added in a later version append to the end of your list; slots removed from the app drop out of it; a corrupt layout file resets to the default instead of breaking the deck.

The status band carries the same information in one line: health mark, version, route name, exit IP, and the auto-rotate toggle. The New IP slot rotates on demand.

Data, updates, and uninstall

OpenDeath keeps user data under your Windows profile:

%APPDATA%\dev.opendeath.desktop\
├─ settings\        theme, routes, and preferences
├─ pending.json     chats waiting for a new route
├─ logs\            local diagnostics
└─ cli\             the bundled engine version

The installed app lives in %LOCALAPPDATA%\Programs\OpenDeath by default. The portable build extracts to a temporary folder each time it runs.

Updates are automatic. The app checks once at launch and every ten minutes, downloads a new build in the background, and asks before it restarts into it. The app menu also has Check for updates. The portable build does not update itself; replace it from the download page. Either way, your settings and waiting chats stay in your profile.

Uninstall from Windows Settings → Apps, or run the uninstaller in the install folder. It removes the app and shortcuts. Your settings and waiting chats are kept so a reinstall can find them; delete %APPDATA%\dev.opendeath.desktop to remove them as well.

Troubleshooting

The setup says OpenCode Desktop is missing

Install the official OpenCode desktop build, then run the OpenDeath wizard again. If it is already installed in a non-standard location, install it per user or add its uninstall entry so the check can find it.

A route will not connect

Press Fix connection and read the Status panel. For WARP, Windscribe, or Mullvad, confirm the client is installed, running, and signed in.None and continue working.

A tab says the session cannot be found

The tab points to a session that was deleted on the server. Current builds close that tab automatically after a moment; you can also close it with the button in the panel. Your other tabs and settings are not affected.

SmartScreen blocks the installer

The build is unsigned. Verify the SHA-256 against SHA256SUMS.txt, then choose More info → Run anyway. Do not run a file whose hash does not match.

The counter or a download link fails

Release files are served from this host. If a download stops, resume it or start again; the checksum is the same. If the page cannot reach the counter, it shows the last known value or the baseline of 59 rather than blocking.
