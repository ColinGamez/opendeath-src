01 — The product

A desktop,
not a dashboard.

OpenDeath is built around a long session: tabs, diffs, a terminal, a browser, and a network deck that stays out of the way until the connection needs work.

01

Eight routes

Auto, WARP, HTTP Proxy, SOCKS5, Route64, Mullvad, Windscribe, or none. WARP is the default. Switch from the deck without leaving the chat.

02

Reset the limit

Clear the current allowance and retry the last prompt in one action, instead of rebuilding the conversation.

03

Rotate without babysitting

Auto-rotate makes up to 50 attempts, remembers burned exit IPs for 24 hours, and stops when the route is healthy.

04

Fix the connection

Diagnose the selected route, rebuild the tunnel, and read the current exit IP from the Status panel.

05

Remember the session

Waiting chats are written to disk. After a relaunch, OpenDeath restores them and sends continue once the new route is ready.

06

Rotation without a restart

WARP keeps the same local proxy across a rotation, so the service reconnects on a new exit without restarting the app.

07

Move the deck

Every slot drags into place, hides behind an eye, and stays where you put it after a restart. Reset puts the shipped order back.

08

Make it yours

Color-named themes, eight accent presets, a 0–200% corner slider, compact or comfortable slots, and a status band you can switch off.

09

Chrome that gets out of the way

The window controls sit on the same surface as the title bar. No grey strip, no second bar — minimize, maximize and close drawn into the window itself.

04 — Before you start

What it needs.

OpenDeath installs beside OpenCode Desktop. It never launches or modifies your OpenCode installation; it uses its own executable, engine, and data folder.

RequirementDetails
WindowsWindows 10 22H2 or Windows 11, 64-bit

RequiredCloudflare WARP, installed by the wizard. Optional: Windscribe, Mullvad, WireGuard.

Install OpenCode

Use the official desktop build. The wizard will detect it in the per-user install folder or the uninstall registry.

Run the wizard

Choose shortcuts and any VPN clients you want. Leave the rest unchecked; the app is complete without them.

Open the deck

Pick Auto or None, then press Fix connection and Status to confirm the route.

Start a session

Work as usual. If a free limit appears, reset it or let Auto-rotate find a new exit.

Stop losing
the session.

Install once. Keep the route healthy, reset the limit, and let the work continue where it left off.
