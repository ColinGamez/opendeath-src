02 — Install

Four steps,
then the deck.

OpenCode Desktop is a required prerequisite. OpenDeath installs beside it and never launches or modifies your OpenCode installation.

Install OpenCode

Use the official desktop build. The wizard looks in the per-user install folder and the uninstall registry.

Run the wizard

Choose shortcuts and any optional VPN clients. Leave the rest unchecked; the app is complete without them.

Open the deck

Launch OpenDeath from the shortcut. Pick Auto or None, then press Fix connection and Status.

Start a session

Sign in to a provider and work as usual. If a free limit appears, reset it or let Auto-rotate find a new exit.

Prefer a walkthrough with route setup and data locations? Read the documentation.
