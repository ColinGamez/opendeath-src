Straight answers.

What OpenDeath is, what it needs, and what it deliberately does not do. If your question is about a route or a setting, the documentation goes deeper.

What is OpenDeath?

A standalone Windows and Linux desktop AI workspace. It combines the OpenCode desktop surface with a network deck: eight routes, automatic rotation, a reset action, relaunch resume, and WARP as the default. It is its own application, with its own executable and data folder.

Is it the same as OpenCode?

No. OpenDeath builds on the OpenCode desktop platform but is a separate, open-source distribution under the MIT License. It is not affiliated with OpenCode. On Windows you install OpenCode Desktop as a prerequisite; the Linux builds bundle their engine. OpenDeath never launches, replaces, or modifies OpenCode.

Why does the setup require OpenCode Desktop?

On Windows, OpenCode Desktop is a required prerequisite for this build. The wizard checks for it before installing anything; if it is missing, the wizard offers the official download link instead of continuing. The Linux packages bundle their engine, so no separate OpenCode install is needed. OpenDeath still installs and runs as its own app.

Do I need a VPN?

No. None is a normal direct connection and Auto works with whatever routes are configured. WARP is required and is the default route; the wizard puts it in place first. WireGuard, Windscribe, and Mullvad are optional, and the free proxy list is the fallback. Add a client only for the route you actually use.

Does OpenDeath use Tor?

No. Tor is not included. The deck runs on WARP, your own proxy list, SOCKS5, Route64, Mullvad or Windscribe, so no traffic leaves through the Tor network and there is nothing extra to trust or configure.

Which providers can I use?

The providers available in your OpenCode sign-in are available in OpenDeath. Model requests go to the provider you configured, through the route you selected. OpenDeath does not proxy provider traffic through an OpenDeath server.

Does OpenDeath collect telemetry?

No. There is no OpenDeath analytics endpoint, crash upload, or usage reporting. Local diagnostics stay in your profile under %APPDATA%\dev.opendeath.desktop\logs.

What happens to a chat when the route changes?

It keeps going. Auto-rotate verifies the new exit, then sends continue to each waiting chat. Waiting chats are saved to pending.json and restored after a relaunch, so closing the app does not throw away the queue.

Why do the themes have color names now?

Because that is what people pick them for. Peach was oc-2, Cornflower was catppuccin-frappe, Lavender was pastel-lavender, and Violet Black was amoled. The theme IDs are unchanged, so the theme you already had selected stays selected after the update; only the label in Settings reads differently.

Can I rearrange the deck?

Yes. Settings → HUD, or the Edit HUD button on the deck. Drag a slot, nudge it with the arrow buttons, or hide it with the eye. The order is saved immediately and survives a restart; Reset restores the shipped layout.

Can I run it on Linux or macOS?

Linux is supported with AppImage, deb and rpm packages, plus a one-command installer that also puts the opendeath CLI on PATH: 

curl -fsSL https://open.death.cl/downloads/install.sh | sh

It detects apt, dnf, pacman or zypper, verifies checksums, and installs the matching package. The Linux build is x86_64 only. The deck drives Cloudflare WARP through warp-cli and falls back to the free proxy list or SOCKS5. macOS is not built.

Why does Windows warn me about the installer?

The build is unsigned, so SmartScreen cannot verify a publisher. Check the SHA-256 against SHA256SUMS.txt, then choose More info → Run anyway. Do not run a file whose hash does not match.

WARP says "Device not authenticated"

The WARP client lost its device registration. That usually happens after many rotations in a row, when Cloudflare rate-limits new registrations. OpenDeath asks for a new registration on its own when WARP is selected, but if Cloudflare is still refusing, run this once in a terminal, then press Fix connection:

"C:\Program Files\Cloudflare\Cloudflare WARP\warp-cli.exe" --accept-tos registration new

Wait a few minutes between attempts; the limit is per address. Until a registration exists, the WARP app cannot connect, and OpenDeath stays on the fallback route.

How do updates work?

Automatically, on the installed build. It checks once at launch and every ten minutes, downloads a new version in the background, and asks before restarting into it. Check for updates in the app menu runs the same check on demand. The portable build does not update itself; grab a new portable from the download page. Your settings and waiting chats stay in your profile.

Why did a tab say the session cannot be found?

The saved tab pointed to a session that had been deleted on the server. Current builds detect that state and close the tab automatically after a moment, so a dead tab does not sit in the strip on every launch. The Close Tab button in the panel also works.

Is the source code available?

Yes. OpenDeath is open source under the MIT License. The application source, build scripts and release tooling are in the public repository. Third-party components and their licenses are listed in the release notices.

How do I uninstall it?

Windows: use Settings → Apps, or run the uninstaller in the install folder. Linux: sudo apt remove opendeath or sudo dnf remove opendeath, or delete the AppImage directory and its menu entry. The app and shortcuts are removed; your settings and waiting chats are kept. Delete %APPDATA%\dev.opendeath.desktop on Windows, or ~/.config/dev.opendeath.desktop on Linux, to remove those as well.
